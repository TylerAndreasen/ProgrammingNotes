# Algorithm X

Popularized by Donald Knuth, Algorithm X is an approach to solving Exact Covering Problems.
An exact covering problem is one in which, given some data set, all options within some range of one parameter of that data set are present within a reported subset. Touchstone examples include Sudoku and the n-queens problem.

The algorithm represents the data set being analized as a doubly linked list, adjascency matrix. This allows for fast addition and removal of nodes.
