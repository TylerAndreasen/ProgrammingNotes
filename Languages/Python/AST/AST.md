# Python AST

The Python module AST, or Abstract Syntax Tree, allows for the parsing of Python code into a syntax tree. This can be very helpful for debugging, and will be a major tool for a upcoming project. For basic use, pass a string containing Python code, and the returned value will be a tree of objects containing the structure of the supplied code, with the values contained as parameters of larger objects.

Given the nature of this upcoming project, this tool makes things even easier than I anticipated. See the example files in the containing directory for what I mean.
