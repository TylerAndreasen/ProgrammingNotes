# MineSweeper in Godot
I intend to create a version of MineSweeper in Godot to relearn it and build a more interesting game than Flappy bird.
What are the high-level elements that I know I will need from a technical perspective:
- Art, this can be plagirized as I do not intend to make this public at any point.
- User Input management
- Board of Cells
- A Cell
- Board Generation
- Informational Header: Mine count, board size,
- Usage of Events: for the purpose of relearning them.

After putting some time into the project while only referencing documentation
and searching for solutions to specific problems, I determined that I did not
know enough about what I was doing and needed some guidance. I found a relevant
tutorial and learned several things including that an AtlasTexture exists as a
way to use a single image file to assign any needed texture to a minesweeper
cell. Truth be told, I have lost a fair bit of motivation for this project
unfortunately. Following this sort of tutorial feels like cheating to me
despite the time spent away from Godot and writing code in general.
